# 👨‍💻 Muhammad Sajjid - Personal Portfolio

A modern, highly responsive, and interactive personal portfolio website built to showcase my skills, projects, and professional experience.

## ✨ Features

- **Modern Tech Stack**: Built with React.js and Vite for blazing-fast performance.
- **Smooth Animations**: Integrated Framer Motion for beautiful page transitions and interactive element animations.
- **Glassmorphism Design**: Premium UI aesthetics using glassmorphism, glowing effects, and a dark theme.
- **Fully Responsive**: Optimized for all devices ranging from mobile phones to large desktop screens.
- **Functional Contact Form**: Integrated with EmailJS to receive emails directly from the website without any backend.
- **Dynamic Projects Section**: Easily manageable list of projects with tags and relevant links.

## 🛠️ Technologies Used

- **Frontend**: React.js 18, JSX, Vanilla CSS
- **Build Tool**: Vite
- **Animations**: Framer Motion
- **Icons**: React Icons (Feather/Si)
- **Services**: EmailJS (for contact form functionality)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm installed on your local machine.

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/ShafaqatIqbal77/Portfolio.git
   ```
2. Navigate to the project directory
   ```sh
   cd Portfolio
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the development server
   ```sh
   npm run dev
   ```

### 📧 Setting up EmailJS

To make the contact form functional:
1. Create an account on [EmailJS](https://www.emailjs.com/)
2. Create an Email Service and an Email Template
3. Update `src/components/Contact.jsx` with your specific keys (`SERVICE_ID`, `TEMPLATE_ID`, and `PUBLIC_KEY`)
